# 🐍 جعبه‌ابزار PyLauncher - تبدیل پرتابل پایتون به EXE

**<span dir="ltr">PyLauncher</span>** یک ابزار قدرتمند و کاملاً پرتابل (قابل حمل) برای تبدیل اسکریپت‌های پایتون به فایل‌های اجرایی (EXE) است که به طور خاص برای محیط‌های محدود طراحی شده است. محیط‌هایی که در آن‌ها نمی‌توانید پایتون، <span dir="ltr">PyInstaller</span> یا هیچ نرم‌افزار جانبی دیگری را نصب کنید.

اگر با محدودیت‌های شبکه شرکت، عدم دسترسی به اینترنت، نبود دسترسی ادمین (Admin) یا آنتی‌ویروس‌های سخت‌گیر مواجه هستید، <span dir="ltr">PyLauncher</span> بهترین راه‌حل برای شماست.

## ✨ قابلیت‌های فوق‌العاده

- **🚀 کاملاً پرتابل (بدون نیاز به نصب):** کل برنامه روی فلش مموری یا پوشه اجرا می‌شود. نیازی به دسترسی ادمین، تغییر رجیستری ویندوز، یا نصب پایتون روی کامپیوتر مقصد ندارد.
- **📦 معماری دوگانه (Dual-Mode):**
  - *حالت تک‌فایلی:* فقط <span dir="ltr">`PyLauncher.exe`</span> را ببرید و اجرا کنید. محیط را در پوشه موقت (Temp) باز می‌کند، کار را انجام می‌دهد و خودش را پاک می‌کند.
  - *حالت پوشه‌ای:* پوشه <span dir="ltr">`env`</span> را کنار فایل اجرایی قرار دهید تا سرعت بالا و نصب دائمی پکیج‌ها را تجربه کنید.
- **🧹 پاکسازی خودکار (Self-Destructing):** در حالت تک‌فایلی، به محض بستن برنامه، تمام فایل‌های موقت از سیستم شما حذف می‌شوند. هیچ فایل آشغالی باقی نمی‌ماند!
- **⚙️ مدیر بسته داخلی (Package Manager):**
  - **بررسی آپدیت:** مشاهده پکیج‌های قدیمی.
  - **نصب آنلاین:** جستجوی پکیج (مثلاً <span dir="ltr">`pandas`</span>)، بررسی حجم و نسخه از طریق API سایت <span dir="ltr">PyPI</span> و نصب آن.
  - **نصب آفلاین:** اینترنت ندارید؟ فایل <span dir="ltr">`.whl`</span> یا <span dir="ltr">`.tar.gz`</span> را از سیستم خود بیاورید و مستقیماً در محیط پرتابل نصب کنید.
- **🕵️ اسکنر هوشمند وابستگی‌ها:** قبل از تبدیل، برنامه کد شما را با استفاده از درخت تجزیه نحوی (AST) آنالیز می‌کند تا ببیند آیا همه کتابخانه‌ها نصب هستند یا نه. کتابخانه‌های ناموجود با رنگ قرمز هشدار داده می‌شوند.
- **🛡️ سازگار با آنتی‌ویروس:** به طور پیش‌فرض از فلگ‌های <span dir="ltr">`--onedir`</span> و <span dir="ltr">`--noupx`</span> استفاده می‌کند. این ساختار به طور چشمگیری احتمال هشدارهای کاذب (False Positive) را کاهش می‌دهد.
- **📥 نمایش زنده پیشرفت دانلود:** کنسول برنامه خروجی <span dir="ltr">`pip`</span> را به صورت زنده خوانده و نوار پیشرفت و حجم دانلود را نمایش می‌دهد.

## 🛠️ نحوه استفاده

### روش اول: فایل اجرایی آماده (تک فایلی)
1. آخرین نسخه <span dir="ltr">`PyLauncher.exe`</span> را از بخش <span dir="ltr">Releases</span> دانلود کنید.
2. آن را در یک پوشه خالی قرار دهید.
3. فایل‌های <span dir="ltr">`.py`</span> خود را کنار آن کپی کنید.
4. روی <span dir="ltr">`PyLauncher.exe`</span> دابل‌کلیک کنید. رابط گرافیکی باز می‌شود، فایل‌ها را اسکن کرده و خروجی را در پوشه <span dir="ltr">`dist`</span> می‌سازد.

### روش دوم: حالت توسعه‌دهنده / پوشه‌ای
1. سورس‌کد و پوشه <span dir="ltr">`env`</span> را دانلود کنید.
2. فایل <span dir="ltr">`PyLauncher.py`</span> و پوشه <span dir="ltr">`env`</span> را در یک مسیر قرار دهید.
3. دستور <span dir="ltr">`env\python.exe PyLauncher.py`</span> را اجرا کنید.
4. *نکته:* در این حالت، هر پکیجی که از طریق منوی <span dir="ltr">Config</span> نصب کنید، برای همیشه در پوشه <span dir="ltr">`env`</span> ذخیره می‌شود.

## 🏗️ ساخت فایل EXE از سورس‌کد

ما یک اسکریپت ساخت خودکار برای شما آماده کرده‌ایم! اگر فایل <span dir="ltr">`converter_gui.py`</span> را تغییر دادید یا پکیج جدیدی نصب کردید، فقط کافیست فایل زیر را اجرا کنید:

</div>

```cmd
Build.bat
```

<div dir="rtl" align="right">

**فایل <span dir="ltr">`Build.bat`</span> چه کارهایی می‌کند؟**
1. مسیر اصلی پروژه را به صورت هوشمند تشخیص می‌دهد.
2. پوشه <span dir="ltr">`env`</span> را با سریع‌ترین ابزار موجود (<span dir="ltr">WinRAR</span>، <span dir="ltr">7-Zip</span> یا <span dir="ltr">`tar`</span> ویندوز) به <span dir="ltr">`env_pack.zip`</span> تبدیل می‌کند.
3. <span dir="ltr">PyInstaller</span> را با استفاده از *پایتون داخلی* (بدون نیاز به نصب پایتون روی سیستم) اجرا می‌کند.
4. فایل نهایی <span dir="ltr">`PyLauncher.exe`</span> را در پوشه <span dir="ltr">`dist`</span> تحویل می‌دهد.

## ⚠️ نکات مهم

- **هشدار آنتی‌ویروس:** چون <span dir="ltr">PyInstaller</span> یک محیط کامل پایتون را در فایل شما قرار می‌دهد، ممکن است برخی آنتی‌ویروس‌های سازمانی سخت‌گیر فایل‌های ساخته شده را به اشتباه مشکوک تشخیص دهند. این یک رفتار شناخته‌شده است (False Positive). پیشنهاد می‌شود از تیم IT بخواهید فایل را در لیست سفید (Whitelist) قرار دهد.
- **تاخیر در اجرای اولیه:** در حالت تک‌فایلی، اولین اجرا ۳ تا ۵ ثانیه طول می‌کشد زیرا برنامه باید محیط پایتون را در پوشه موقت باز کند.
